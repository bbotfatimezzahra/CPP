# 🧩 CPP Modules — C++ Piscine

A collection of C++ modules from the **1337 (42 Network)** curriculum, covering the fundamentals of Object-Oriented Programming, memory management, and modern C++ concepts.

Each module (`CPP00` through `CPP09`) introduces a new set of concepts through small, focused exercises.

---

## 📦 Modules Overview

| Module | Focus | Key Concepts |
|--------|-------|--------------|
| **CPP00** | Namespaces, classes, member functions | `std::string`, `iostream`, encapsulation, `static` |
| **CPP01** | Memory allocation, pointers to members, references | `new`/`delete`, references vs pointers, file streams |
| **CPP02** | Ad-hoc polymorphism, operator overloading | Orthodox Canonical Class Form, fixed-point numbers |
| **CPP03** | Inheritance | Base/derived classes, access specifiers, diamond problem |
| **CPP04** | Subtype polymorphism, abstract classes, interfaces | Virtual functions, pure virtual, deep copy vs shallow copy |
| **CPP05** | Repetition and exceptions | Try/catch/throw, custom exceptions, nested classes |
| **CPP06** | C++ casts | `static_cast`, `dynamic_cast`, `const_cast`, `reinterpret_cast` |
| **CPP07** | Templates | Function templates, class templates, template specialization |
| **CPP08** | Templated containers, iterators, algorithms | STL containers, iterators, generic algorithms |
| **CPP09** | STL | `std::map`, `std::vector`, `std::deque`, algorithm usage |
